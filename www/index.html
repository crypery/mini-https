mini-c-server

HTTP/1.1 + HTTPS + WebSocket + SSE + multipart upload, written in C (select() + thread pool). All endpoints below are live.

GET /api/info

Server statistics and your request headers, returned as JSON.

Click the button to load server info.

GET /ws — Live Server Logs

WebSocket streams every server log line into the box below. Try opening the other buttons/tabs — you will see their requests appear here in real time.

GET /sse — Notifications

Server-Sent Events push connected and tick events.

SSE is stopped.

POST /api/upload

Uploads a file (multipart/form-data) to the upload_dir configured in config.json.

Select a file and upload it.

POST /api/form

Sends the text HelloWorld! as the raw request body; the server echoes it back as the message.
